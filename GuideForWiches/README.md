# 新米魔女のためのタイジュの里ガイドブック

## はじめに

これを読むあなたは、いま、すごく、驚いていることでしょう。目を開けると見渡す限りの森が広がっていて、「じぶん」というものが存在しているからです。手、と、足、というのが何かは教えてもらいましたか？なかなか、便利でしょう？

### あなたは何なのか

わたしたちにも、わかりません。ですが、わたしたちは、とりあえず、「魔女」、と呼んでいます。何か「ことば」で指し示せると便利だからです。どうして「魔女」というかと言いますと、後述する「魔法」が使える、（おそらくは）唯一の生き物だからです。あなたは、この世界に生まれました。

### ここはどこ？

わたしたちにも、わかりません。ですが、同じように、とりあえず、「タイジュの里」と呼んでいます。周りにたくさんあるみどり色に驚いた事かと思います。これは「植物」と呼ばれている、あなたと同じように動く、「生き物」です。ここには、他にもたくさんの生き物たちが生息しています。ひとまず落ち着いたら、いろいろ観察してみてください。

### ひとまず、落ち着いて。

あなたを見つけた魔女も、きっと驚いているに違いありません。ここは、見つけてくれた魔女と一緒に読んでくださいね。あなたのような魔女

とりあえず、服を着ましょう。服が何なのかわからない場合は、ことばより実物を見たほうが早いので、近くの魔女に聞いてください。服を着ていないと、風邪というものになってしまいます。すると、きっと、このガイドを次へと読み進める元気もきっとなくなってしまいます。服はきっと、見つけた魔女がいったん着るぶんは用意してくれることでしょう。貸してもらうとよいです。大丈夫、その魔女も、生まれたときはだれかに借りた

### 困った時は

#### 想像をしてみよう

どうするか、困るときがあります。その時は、とりあえずあなたの中で実際にやってみてください。魔女はみんな、とても想像が得意なので、きっとあなたも得意でしょう。すると、たまに、ですが、すごくむずむずするような…、はやく忘れたくなるような…、この想像をいますぐ辞めたくなるような…、そんな気持ちになる事があります。とりあえず、そういう事はやらないほうがいいです。

### 姉妹

同時に複数の魔女が同じ場所で生まれることが確認されています。あなたも生まれたとき、やっぱり、うまれたての、右往左往して困って言う魔女が近くにいましたか？

でしたら、同時に生まれた魔女同士は、「姉妹」になる事が多いです。姉妹とは、「妹」と「姉」がいる、という関係です。どちらが妹になるか、姉になるか、それは自由です。

もちろん、姉妹にはならないも悪いことではありません。それでも、きっとあなたにとって、掛け替えのない
