# 新米魔女のためのタイジュの里ガイドブック

## はじめに

これを読むあなたは、いま、すごく、驚いていることでしょう。目を開けると見渡す限りの緑色（森、と呼んでいます）が広がっていて、「じぶん」というものが存在しているから、ではないでしょうか。手、と、足、というのが何かは教えてもらいましたか？なかなか、便利でしょう？

色々と驚き、混乱しているかと思います。少しずつで構いませんので、読み進めていってください。

### あなたは何なのか

わたしたちにも、わかりません。ですが、わたしたちは、とりあえず、「魔女」、と呼んでいます。何か「ことば」で指し示せると便利だからです。どうして「魔女」というかと言いますと、後述する「魔法」が使える、（おそらくは）唯一の生き物だからです。あなたは、そんな魔女の１人、だと思われます。

#### 生まれたって何？どういうこと？

とりあえず、わたしたちが、今までに分かっていることをお伝えします。わたしたち、魔女は、どうも、気が付くと、勝手に「どこからか、出てきてしまう」ようなのです。

「そこにさっきまで、魔女は居なかったのに、気がつくと、魔女がいる」

分かっていることは、ただ、それだけです。そして、あなたもその「出てきてしまった」魔女の一人、ということになります。わたしたちは、この現象を「魔女が生まれた」と呼んでいます。

### ここはどこ？

わたしたちにも、わかりません。ですが、とりあえず、「タイジュの里」と呼んでいます（あとで詳しくご紹介します）。周りにたくさんある緑色に驚いた事かと思います。これは「植物」と呼ばれている、あなたと同じように生まれ、過ごしている（「生きる」、と言います）、「生き物」です。でも、あなたやわたしたちとは色々違う生き方をしています。ここには、他にもたくさんの生き物たちが生きています。ひとまず落ち着いたら、いろいろ観察してみてください。

### ひとまず、落ち着いて。

あなたを見つけた魔女も、きっと驚いているに違いありません。ここは、見つけてくれた魔女と一緒に読んでくださいね。

とりあえず、服を着ましょう。服が何なのかわからない場合は、ことばより実物を見たほうが早いので、見つけてくれた魔女に聞いてください（見つけた魔女は、教えてあげてください）。

見つけた魔女へ：服を貸してあげてください。

生まれた魔女へ：貸された服を、着てみてください。そして、いつか服を返してください。

そんなわけで、

服を着ていないと、風邪というものになってしまいます。すると、きっと、このガイドを次へと読み進める元気もきっとなくなってしまいます。

服を着ましたか？では、次へ進みますね。
